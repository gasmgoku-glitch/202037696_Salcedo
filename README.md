**Curso:** Lenguajes Interpretados (202037696) – UNAD

**Actividad:** Tarea 5 – Proyecto en GitHub y Artículo de Sustentación

**Autor:** Gustavo Salcedo Mercado – Ingeniería Electrónica, CCAV Corozal

**Modalidad:** Individual

## Descripción del Proyecto
Este repositorio integra los módulos desarrollados durante el curso Lenguajes Interpretados: Tareas 2 y 3, para la gestión energética de un nodo solar fotovoltaico:

1. **Módulo de Gestión de Baterías (INA219):** control condicional de voltaje para un banco de 24 V con protección por software y límites de muestreo.
2. **Módulo del Controlador Solar (Phocos MPPT):** mapa de memoria jerárquico mediante diccionarios anidados y script de consulta segura de registros mediante el método `.get()`.

## Roles técnicos asumidos
Líder de Integración, Auditor PEP 8, Redactor Técnico y Revisor de Calidad.

El código del sistema sigue la guía de estilo PEP 8.
